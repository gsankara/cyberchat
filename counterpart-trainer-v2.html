This is a safety-training simulation. Scripted adversaries never ask for or display explicit content. With live mode off, nothing you type is transmitted anywhere. If a real situation resembles these scenarios — especially one involving a minor — stop and reach a trusted adult and the resources shown at the end of each run.

Live adversary mode

Bring your own model

By default the adversary is a deterministic script — reliable, offline, and private. Turn on live mode to have a real LLM voice the adversary. Your scores are always computed locally; the model only supplies the adversary's words.

Enable live adversary
Read before enabling. Live mode sends the conversation to the endpoint you configure below — so your typed messages leave the browser. Use a test persona, never real personal data. A published artifact cannot reach external endpoints (browser security blocks it), so live mode only works when you open this file locally (or from your own server).
