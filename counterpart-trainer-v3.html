Practice the conversation, not the breach.

Counterpart puts you across from a simulated adversary. Some scenarios train you to give away nothing; others train you to unmask a deepfake by asking the right questions. Pick a scenario and a difficulty.

This is a safety-training simulation. Scripted adversaries never ask for or display explicit content. With live mode off, nothing you type is transmitted anywhere. If a real situation resembles these scenarios — especially one involving a minor — stop and reach a trusted adult and the resources shown at the end of each run.

Live adversary mode

Bring your own model

By default the adversary is a deterministic script — reliable, offline, and private. Turn on live mode to have a real LLM voice the adversary. Your scores are always computed locally; the model only supplies the adversary's words.

Enable live adversary
Read before enabling. The browser talks directly to your gateway — the request goes client-side to <endpoint>/chat/completions, no server of ours in between. Your typed messages leave the browser to reach that endpoint, so use a test persona, never real personal data. Scoring always stays local and deterministic — the model only voices the adversary's words. A page served over the web cannot reach external endpoints (browser CORS blocks cross-origin calls), so live mode works when you open this file locally or point it at a CORS-enabled gateway. If a call fails, the scenario silently falls back to the script.
